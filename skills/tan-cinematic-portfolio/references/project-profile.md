# Source Project Profile

## Stack

- Next.js 15, React 19, TypeScript.
- Tailwind CSS 4 through PostCSS.
- `next/font` with Outfit and Playfair Display.
- GSAP 3 + ScrollTrigger.
- Framer Motion 12.
- Lenis smooth scrolling.
- Three.js, React Three Fiber, and Drei.
- OGL for an isolated lightweight particle effect.
- Lucide React for interface icons.

## Page Sequence

1. Dark full-screen 3D hero.
2. Dark spatial skill marquee.
3. Blind transition into a white about section.
4. White scroll-driven ribbon evolution.
5. White long-form 3D project theatre.
6. White editorial sticky project grid.
7. Blind transition back to dark.
8. Dark orbital closing CTA.

The sequence creates tension and release: spectacle, clarity, proof, then conversion.

## Installed Repository Skills

- `design-taste-frontend`: audit-first anti-template portfolio and landing-page design.
- `gsap-core`: GSAP tween, easing, stagger, responsive, and reduced-motion guidance.
- `gsap-performance`: transform-first animation performance guidance.
- `high-end-visual-design`: agency-style typography, spacing, depth, and motion rules.
- `minimalist-ui`: warm editorial minimalism and flat bento patterns.
- `redesign-existing-projects`: targeted upgrades to existing interfaces without rewrites.

The source project combines the cinematic direction from the high-end skills with the editorial discipline of the minimalist skill. Apply `minimalist-ui` selectively to light sections because its no-gradient/no-3D constraints conflict with the dark cinematic stages.

## Design Diagnosis

Strengths:

- Recognizable amber/black identity.
- Strong sans/serif contrast.
- Clear alternation of immersive and editorial modes.
- 3D visuals communicate continuity, systems, evolution, and work.
- Layouts avoid generic centered-card templates.
- Responsive hero composition and capped DPR show performance awareness.

Inconsistencies:

- Tokens exist only partially; many colors and radii are repeated as literals.
- Both Framer Motion and GSAP handle nearby entrance/scroll concerns.
- Purple atmosphere appears outside the dominant amber system.
- Some shadows and blur layers are heavier than the otherwise restrained language.
- The UI claims performance excellence while reduced-motion and off-screen rendering remain incomplete.

Preserve the visual identity first. Consolidate tokens and animation ownership only when editing those surfaces; do not rewrite the whole project for architectural purity.
