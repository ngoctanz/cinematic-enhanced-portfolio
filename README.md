# cinematic-enhanced-portfolio

Cinematic portfolio design skill for AI coding agents.

## Install

```bash
npx skills add ngoctanz/cinematic-enhanced-portfolio \
  --skill tan-cinematic-portfolio \
  --agent codex
```

Install globally without prompts:

```bash
npx skills add ngoctanz/cinematic-enhanced-portfolio \
  --skill tan-cinematic-portfolio \
  --agent codex \
  -g -y
```
